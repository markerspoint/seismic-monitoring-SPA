✨ Features
🗺 Interactive Map

• Leaflet-powered live map

• Triangular marker for the latest earthquake

• Circle markers scale dynamically with magnitude + zoom

• Clean color system based on magnitude levels

• Collapsible magnitude legend

• Fullscreen map mode (mobile)

📡 Real-Time Earthquake Feed

• Pulls latest data from your custom Node/Express API

• “Last Updated” dynamic timestamp

• Earthquake list synced across mobile + desktop

🔍 Filtering

• Minimum-magnitude filter (desktop + mobile synced)

• Tap markers for detailed earthquake info

• Direct link to PHIVOLCS report (if provided)

📍 Location Support

• Use My Location button

• Accuracy radius indicator

• Smart location-permission modal with cooldown

📱 Mobile Optimized

• Slide-in panel for recent earthquakes

• Mobile navigation overlay

• Sticky footer for persistent footer info

• Smooth map resizing & fullscreen mode

• Layout adjusts cleanly from mobile → desktop

🎨 UI / UX

• Modern TailwindCSS dark theme

• Responsive text using clamp()

• Smooth gradients, blur, rounded UI, and drop shadows

• Animated transitions for interactions

• Well-polished modals, popups, and UI overlays
